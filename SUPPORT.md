# Support

## Community (free)

- **Bugs / feature requests:** [GitHub Issues](https://github.com/xrey167/FinX-Plattform/issues)
  (templates provided).
- **Questions / show-and-tell:** GitHub Discussions (being enabled).
- **Security reports:** see [SECURITY.md](SECURITY.md) — please do not open
  public issues for vulnerabilities.

Best-effort responses; the issue templates and the docs under
[`docs/products/`](docs/products/) and [`docs/release/`](docs/release/) answer
most setup questions (quickstart, install, backup/restore, upgrades).

## Commercial support (paid)

For teams running the self-hosted warehouse or embedding tdw in production:

| Tier | What you get |
|---|---|
| **Onboarding** | Guided install of the compose stack or MCP server in your environment, provider/key setup, runbook walkthrough. Fixed-price engagement. |
| **Support contract** | Named contact, response-time SLA, upgrade assistance across releases, priority bug fixes. Annual. |
| **Custom development** | New providers, custom endpoints/tools, integration work — scoped and quoted. |
