# schemas

## Purpose

The 11 BOM (Business Object Model) schema specifications — the canonical
domain shape for the entire FinX-Plattform. These were re-derived from
scratch from a curated OSS source list (see `00_provenance.md`); **no**
FinX-XR sources are in the corpus. The Rust structs in
`../../crates/tdw-domain/src/lib.rs` mirror these specs one-to-one.

Drift between spec and code is caught by
`cargo run -p xtask -- schema-sync`. Generated JSON Schemas land in the
`agent/`, `event/`, `protocol/`, and `config/` subdirectories.

## For AI Agents

### Working In This Directory

- **Edit the markdown spec first, then the Rust struct.** Running
  `xtask schema-sync` after editing only the Rust side will catch the drift,
  but the human-readable spec is what other agents read.
- **The 11-schema set is closed.** A new domain (e.g. crypto-DEX, derivatives
  greeks) lands as an additional section in the relevant existing schema, not
  as a 12th file.
- **Generated subdirectories are read-only to humans.** Re-run the matching
  `xtask` command after touching the upstream Rust type.
