# Plans

The source planning package is copied into `.plans/` for local traceability. The
bootstrap implementation follows the Phase 0/0.5 slice:

- Rust workspace and crate stubs.
- Docker Compose profiles.
- CI/GitHub scaffolding.
- Worktree and Git workflow.
- Compile-ready core/domain/runtime foundation.

The later feature phases remain plan-backed but intentionally unimplemented in this
bootstrap pass.
