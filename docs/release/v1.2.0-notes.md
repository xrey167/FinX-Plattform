# Release Notes — v1.2.0

The "live data, for real" release. v1.1.0 wired real engines into the
self-hosted stack; v1.2.0 makes the **MCP financial-data server** (Product ①)
actually serve live market data end to end — verified by driving the server as
a real MCP client and fixing everything that 2026's provider APIs broke.

## Highlights

### Live market data over MCP

- A new `live` cargo feature on `tdw-mcp` swaps the offline Yahoo fixture for
  the real HTTP fetcher and registers every live HTTP provider — 34 providers
  (51 fetcher endpoints) vs 3 offline (#269). All distribution artifacts —
  GHCR images (#271) and tagged release binaries (#272) — build with it.
- `tdw.provider.fetch`: a generic tool dispatching **any** compiled-in fetcher
  by `(provider, endpoint)`, with a drift-guard test pinning dispatch
  completeness (#274). Previously only yahoo + fileset were callable.
- Honest surface: `.sample` evidence tools are hidden from the default
  `tools/list` (#273), and the server discloses fixture-vs-live data mode in
  its `initialize` instructions and tool descriptions (#274).

### Provider transports verified against the real APIs

Every keyless provider's env-gated live test was run against the live service
and the breakage fixed (#267, #268):

- **Yahoo**: anonymous `quoteSummary`/quote/options requests now get
  401 "Invalid Crumb" — added a lazy cookie+crumb handshake (browser UA on the
  handshake path only; offline tests never touch the network).
- **SEC EDGAR**: CIKs normalized from the zero-padded wire form; XBRL revenue
  extraction now falls back through the post-ASC-606 us-gaap concepts.
- **Binance**: new live websocket subscribe test (first real BTCUSDT trade tick
  asserted); **CoinGecko**: the documented live test now exists and passes.

### Documentation for users, not just contributors

- [`docs/products/mcp-quickstart.md`](../products/mcp-quickstart.md): zero to
  live AAPL bars in Claude in under 10 minutes — GHCR one-liner, from-source
  build, Claude Code/Desktop wiring, and the full per-provider API-key table
  (#271, #272).
- [`docs/products/mcp-tool-surface-audit.md`](../products/mcp-tool-surface-audit.md):
  the audit that drove this release, performed as a raw JSON-RPC MCP client.

### Quality and CI

- Per-crate `pedantic`+`nursery` deny across the 58 lint-clean crates (#257)
  and a performance benchmark + regression ratchet in `xtask` (#263).
- Container Image jobs use a buildx GHA layer cache with a 120-minute
  cold-cache backstop — main-push image builds previously died at the 60-minute
  job timeout under QEMU (#270).
- Nightly live-smoke job: provider live tests + an MCP E2E live-bars check
  (#275).
- G005–G007 hardening landed via two history reconciles (#264, #265): bounded
  HTTP clients everywhere (shared `build_client` with connect/request
  timeouts), protocol-level validator coverage for new ops, and the hooks
  deny→ask reconciliation.

## Upgrade notes

- **Offline builds disclose themselves.** A `tdw-mcp` built without
  `--features live` now says so in its MCP `initialize` instructions and tool
  descriptions; market-data results are deterministic fixtures. If you embed
  tdw-mcp and want live data, build with `--features live` (the published
  images and binaries already do).
- **Yahoo handshake egress.** Live yahoo profile/quote/options fetches may now
  contact `fc.yahoo.com` and `query1.finance.yahoo.com/v1/test/getcrumb` once
  per failed-auth retry. Allow these hosts if you run egress-filtered.
- **Keyed providers are env-var configured** — see the quickstart's API-key
  table; keys are read at fetch time and missing keys surface as tool errors,
  not startup failures.
- No protocol, persistence, or operator-contract breaks: MINOR release.
