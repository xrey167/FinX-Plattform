# Release Notes — v1.6.0

> **Status: pending tag.** Bundles the OpenBB-parity-total program — G001–G005,
> PRs #430–#436 — merged to `main` after the v1.5.0 tag.

The **total-OpenBB-parity release.** v1.6.0 closes the OpenBB-parity gap to its
honest floor: **every OpenBB command that has a documented public API — free *or*
paid — is now built**, the paid ones key-gated and dormant until a key is
configured. The endpoint catalog grows from **216 routes** (v1.5.0) to **267
routes** — **195 `Fetch` routes** (up from 169) + **72 `Compute` routes**
(technical 31 / quantitative 21 / econometrics 15 / portfolio 5). The generated
OpenAPI 3.1 document carries **195 paths**, one per `Fetch` route.

This is a **MINOR** release: all changes are backward-compatible additions.
No protocol, persistence-schema, or operator-contract breaks.

## Why this release exists

v1.5.0 closed the *keyless / free-key* OpenBB surface. v1.6.0 finishes the job:
it builds out the **paid-key** providers (key-gated), the **previously-deferred
free clusters** that were mislabeled, and the **compute-router remainder**, then
runs a final web-verified assessment of the no-API scrape sources. The result is
**total parity** — no OpenBB command remains unbuilt merely for lack of a
*documented* API. The only residual is sources with no public API at all
(stockgrid, wsj, finviz, multpl), which is a **source decision, not an
engineering gap**.

- **compute-router remainder (G003b, #433):** the econometrics / quantitative /

## The honest residual

Total parity has a precise floor. Two buckets remain, and **only the first is a
true gap**:

- **No public API — scrape / undocumented-internal sources** (a source decision,
  not an engineering gap):
  - **stockgrid** (`equity/shorts/short_volume`) — no documented public API;
    OpenBB hits an undocumented internal endpoint (confirmed by **OpenBB issue
    #503**). Parity served by FINRA short-interest + SEC `fails_to_deliver`.
  - **wsj** (etf / `equity/discovery`) — no documented public JSON API. Parity
    served by FMP discovery + Yahoo price/performance.
  - **finviz** (`equity/screener`, `equity/compare/groups`) — HTML-scrape only,
    ToS-sensitive. Parity served by FMP screener + Yahoo.
  - **multpl** (`index/sp500_multiples`) — scrape-only; already covered via NASDAQ
    Data Link `MULTPL`.
- **Paid-key-gated — BUILT, dormant without a key** (not unbuilt commands):
  **intrinio** (options, reported_financials, forward P/E), **benzinga premium**
  (`analyst_search`), **tiingo** (`trailing_dividend_yield`).

Tell us which key/budget to provision and the second bucket un-defers
immediately. The first bucket closes only if a vendor publishes official API docs.

## Engineering notes

- Every route is clean-room: a `<Provider>Raw` serde struct normalizes to a
  standard `tdw-domain` model (no raw shapes leak past the fetcher) → a catalog
  route with ordered provider candidates → a daemon dispatch binding.
- Every wave was 3-lens adversarially reviewed, folded the automated
  Gemini-code-assist review (HIGH/MEDIUM findings fixed forward), and passed the
  three-artifact drift gate (OpenAPI, Python SDK, Workspace widgets golden) plus
  the clippy pedantic+nursery ratchet at **0**.
- Counts in this note are verified directly against the catalog
  (`tdw-endpoint-catalog::catalog()`) and `docs/schemas/openapi.json` (195
  paths).

## Upgrade notes

- **No breaking changes.** New routes are additive; existing routes and the
  daemon / MCP / REST contracts are unchanged.
- New providers resolve through the existing provider-candidate path; **key-gated
  providers (intrinio, benzinga-premium, tiingo) stay dormant** unless their key
  is configured. No new required environment variables.
