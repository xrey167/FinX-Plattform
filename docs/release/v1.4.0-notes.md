# Release Notes — v1.4.0

> **Status: pending tag.** Bundles every change merged to `main` after the
> v1.3.0 tag (72 commits, PRs up to #417).

The **intelligent-knowledge release.** v1.2.0 made the MCP financial-data
server (Product ①) production-ready; v1.3.0 did the same for the self-hosted
warehouse stack (Product ②). v1.4.0 turns the knowledge graph (Product ③) into
a self-operating, self-learning system: zero-config first run, six autonomy
loops, a real learning-and-trust layer with eval-gated promotion, and an OpenBB
Workspace graph-visualization widget — plus the close-out of OpenBB-parity
Phase 3 (catalog at **131 routes / 98 provider candidates**).

This is a **MINOR** release: all changes are backward-compatible additions.
No protocol, persistence-schema, or operator-contract breaks.

## Highlights

### Knowledge system: zero-config and observable (K-E)

- **Zero-config first run** (#358): the knowledge graph defaults to an
  in-memory backend on first use — no Bolt/PostgreSQL required to evaluate it.
  Bolt connection failures now emit actionable errors, and the quickstart is
  unified across MCP/REST/CLI.
- **`tdw.kg.status` observability** (#360): one call reports backend, counts,
  embedder, and health across MCP, REST, and CLI.
- **Public ingestion seam** (#359): MCP/REST/CLI all write through a single
  `KnowledgeIndexer` boundary — one validated path in, no backend-specific
  ingestion code.

### Knowledge system: six autonomy loops (K-L)

- **Rules + inference in the daemon** (#365): the rule engine and inference
  run inside the `KnowledgeRuntime`, not as an offline batch.
- **Host-bound agent identity** (#376): agents act under session-derived
  principals — no caller-supplied agent ids (closes an identity-spoof class).
- **Scheduled retrieval evals + drift alarm** (#375), **consolidation tick**
  (#377), **gated auto-materialization sweep** (#380), and **scheduled
  KnowledgeFeed pipelines** (#382): the graph maintains, evaluates, and extends
  itself on a schedule, every mutation routed through the writeback gate.

### Knowledge system: market-grade retrieval & widgets (K-M, K-X)

- **GraphRAG answers** (#404): `tdw.kg.answer` returns cited, point-in-time,
  extractive synthesis (keyless).
- **LLM extraction-as-proposals** (#401), **episodic memory** (#396),
  **contradiction-driven temporal invalidation** (#392), and a **published
  knowledge benchmark suite** (#405: recall/MRR/latency, nightly, drift-stamped).
- **Provenance & explainability**: `tdw.kg.why` + `tdw.kg.diff` time-travel
  (#362), trust-dial retrieval by provenance class (#394), self-narrating
  digest + staleness surfacing (#407), open questions that self-answer (#403),
  knowledge watchlists (#398), thesis tracking (#391), first-class analyst
  findings (#366), session→findings distillation (#413), and portable
  research-trail export (#412).
- **Knowledge graph-visualization widget** (#415): an OpenBB Workspace widget
  rendering ego-graphs and the taxonomy.

### Knowledge system: real learning & trust layer (K-R)

Every behavior change is a **gated proposal**, never a silent mutation:

- **Lessons-as-proposals** (#406) and **pattern→rule induction** (#400):
  agent behavior changes only through B9's gate plus walk-forward eval.
- **Skill lifecycle + eval tournaments** (#408) and **eval-gated parameter
  self-tuning** (#409): skills and system parameters promote/retire only on
  measured improvement.
- **Deterministic motif mining + analogy recall** (#381), **per-fact
  confidence** from corroboration and survived contradictions (#397),
  **walk-forward knowledge validation** replay harness (#393), and **governed
  forgetting** — gated, reversible retirement to a cold plane (#411).

### OpenBB parity: Phase 3 closed

The catalog reaches **131 routes / 98 provider candidates** (84 `Fetch` + 47
`Compute`; OpenAPI 84 paths / 29 schemas):

- **`tdw-analytics-portfolio`** (#361): portfolio metrics Compute routes.
- **`tdw-provider-imf`** (#367, IMF SDMX-JSON) and **EconDB** (#369): macro
  series breadth.
- **`tdw-provider-famafrench`** (#355): Ken French Data Library factors.
- **Estimates breadth** (#371): FMP price-target consensus + forward analyst
  estimates into `tdw_domain::Estimate`.
- **XLSX export from any result envelope** (#372): pure-Rust `rust_xlsxwriter`,
  no C in the dependency tree.
- **Niche-provider deferral, documented** (#373) and **P3 cutover scoreboard**
  (#374): the remaining gap-matrix rows are deferred by explicit clean-room
  decision (paid feeds, or providers with no verifiable public API) — not
  oversights. See [`docs/roadmap/openbb-gap-matrix.md`](../roadmap/openbb-gap-matrix.md).

### Reliability & hygiene

- **Live engine wiring** (#368): the `real-engines` feature chain is wired with
  eager graph-backend validation at boot.
- **Deterministic clock for `McpServer`** (#414) and **corrected Julian day
  math** (#399): date-brittle tests are now reproducible.
- **Clippy pedantic+nursery ratchet held at 0** across the release (#370, #379,
  #395, #402, #410, #416), and dependency bumps (candle 0.10, prost 0.14.4,
  zip 7.2, codecov-action 7, setup-qemu 4).
- **CI review-gate checklist** (#417): the release/schema-drift/clock/rebase
  gate gaps learned this cycle are now codified in
  [`docs/review-gate.md`](../review-gate.md).

## Upgrade notes

- **No breaking changes.** No protocol, persistence-schema, or operator-contract
  breaks. Existing deployments upgrade in place.
- **Knowledge graph default.** First run with no backend configured now uses an
  in-memory graph. To persist, configure Bolt/PostgreSQL as before — behavior
  for configured deployments is unchanged.
- **New optional providers** (IMF, EconDB, Fama-French) are keyless/academic
  and resolve through the existing provider-candidate path; no configuration is
  required to ignore them.
